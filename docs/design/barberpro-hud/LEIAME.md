# Referências visuais — BarberPro "Ouro HUD" (v2)

Estes arquivos são **só referência de visual**. Abra como texto (o estilo está nos atributos `style`); não precisa rodar.
Os dados (nomes, preços, horários) são exemplos.

- `00-kit-componentes.html` — peças base: botões, campos, chips, interruptor, etiquetas, avisos, vazio/carregando, toast, modal, bottom sheet, abas, cabeçalho, QR/link, foto, tabela, texto legal. Toda tela sem desenho próprio usa isto.
- `c01`–`c14` — site do cliente (identificação, modo, chat IA, serviços com foto, profissional, horário, confirmar, avaliação, Pix auto/manual/aguardando, agendado, consulta, meus agendamentos).
- `b01`–`b11` — painel do barbeiro (login, cadastro, início, agenda, estados do atendimento, clientes, serviços, fidelidade e listas, financeiro, configurações, assinatura).
- `p01`–`p02` — landing e pagar fatura.

Quadros altos (kit, início, estados, financeiro, landing…) são rolagens completas da tela, não telas fixas.
O mapa tela-a-tela está em `PROMPT_CLAUDE_CODE.md`.
